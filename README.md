# Website SEO — Jaringan Komputer dan Teknologi

## Sebelum dipublikasikan
1. Ganti semua teks `NAMA WEBSITE` / `Nama Website Anda` dengan nama pilihanmu.
2. Ganti `Nama Anda` pada meta author dengan nama penulis.
3. Pada `artikel-wifi.html`, ganti URL canonical contoh `https://USERNAME.github.io/NAMA-REPOSITORY/artikel-wifi.html` setelah website online. Jika belum memiliki URL final, kamu boleh menghapus baris canonical sampai siap.
4. Baca ulang artikel dan sesuaikan dengan gaya bahasamu. Pastikan isi tetap akurat dan bermanfaat.

## Isi folder
- `index.html` — halaman utama.
- `artikel-wifi.html` — artikel SEO lebih dari 500 kata.
- `styles.css` — desain responsif.
- `assets/wifi-network.svg` — ilustrasi orisinal untuk artikel dan halaman utama.

## Cara publikasi gratis menggunakan GitHub Pages
1. Buat akun di https://github.com/ jika belum punya.
2. Klik **New repository**. Beri nama sederhana, misalnya `website-jaringan`, pilih **Public**, lalu buat repository.
3. Unggah semua file dan folder dari paket ini ke root repository. Pastikan `index.html`, `artikel-wifi.html`, `styles.css`, dan folder `assets` terlihat pada tingkat teratas.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses publikasi. URL umumnya berbentuk `https://USERNAME.github.io/website-jaringan/`. Ganti `USERNAME` dan nama repository sesuai milikmu.
7. Buka URL tersebut dan tes link artikel. URL artikel akan berakhir dengan `/artikel-wifi.html`.
8. Salin URL website dan URL artikel untuk pengumpulan tugas.

## Checklist SEO dan pengumpulan
- [ ] Nama website dan identitas penulis sudah diganti.
- [ ] Artikel sudah dibaca ulang dan dipublikasikan.
- [ ] Title, meta description, H1, subjudul, gambar alt text, dan internal link tersedia.
- [ ] Screenshot halaman utama dan artikel sudah diambil.
- [ ] Siapkan keyword target: **cara mengoptimalkan jaringan WiFi**.
- [ ] Tulis refleksi singkat tentang proses pembuatan dan hal yang dipelajari.
- [ ] Masukkan URL website, URL artikel, keyword, screenshot, dan refleksi sesuai instruksi e-learning.
- [ ] Jika tersedia, tambahkan properti website di Google Search Console dan kirim sitemap atau lakukan inspeksi URL. GitHub Pages tidak menjamin artikel langsung terindeks.

## Catatan
Website ini statis dan tidak memerlukan database. Font dari Google Fonts membutuhkan internet; bila tidak tersedia, website tetap memakai font cadangan. Tautan sumber bacaan pada artikel adalah tautan eksternal untuk referensi lebih lanjut.
